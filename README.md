# websec.lab

Интерактивный однофайловый курс по основам веба — тот фундамент, который нужен AppSec-инженеру до того, как учить уязвимости. Без зависимостей, без бэкенда, работает офлайн: `index.html` — это весь проект.

**[→ Открыть курс](https://mxxnbm.github.io/websec-lab/)**

## Что внутри

17 модулей одним маршрутом: от «что такое интернет» до модели безопасности браузера.

| Секция | Модули |
|---|---|
| **BASICS** | Что такое веб · Сеть, IP и DNS · HTTPS и TLS · URL, origin и site |
| **PROTOCOL** | HTTP: язык веба · Версии, прокси, кэш |
| **CLIENT** | HTML, CSS, JS · Браузер изнутри |
| **ARCHITECTURE** | Web 1 → 2 → сегодня · API: REST и другие |
| **STATE** | Cookies и сессии · AuthN и AuthZ |
| **BROWSER SECURITY** | Same-Origin Policy · CORS · CSP · Security headers |
| **NEXT** | Карта OWASP Top 10:2025 · Флеш-карты |

Каждый модуль устроен одинаково: теория простым языком → схема → интерактивная лаба → SEC-врезка с углом атакующего → блок «на собесе спросят» → ссылки на первоисточники.

**19 лаб.** Сборщик CORS-запроса показывает, полетит ли preflight и почему. Конструктор CSP оценивает политику по шести известным векторам обхода. Переключатель флагов cookie строит матрицу того, от чего защищает каждая комбинация.

**12 SVG-схем** — DNS-резолвинг, chain of trust, процессы Chrome, OAuth Code Flow с PKCE. **6 квизов на 42 вопроса** на active recall. **72 флеш-карты.** Поиск на `Ctrl+K`. Перенос прогресса между устройствами строкой.

## Достоверность

82 ссылки на MDN, RFC, WHATWG, OWASP, PortSwigger, web.dev. Ключевые утверждения сверены со спецификациями, а не с пересказами. Отдельно поправлены две ошибки, которые массово тиражируются по конспектам: `X-Requested-With` **не** входит в CORS-safelist и потому триггерит preflight, а `Access-Control-Allow-Credentials` управляет cookies, но **не** заголовком `Authorization`, который приложение проставляет из JS.

## Приватность

Бэкенда и аналитики нет, наружу курс не ходит. Прогресс лежит в `localStorage` под ключами `wsl.progress` и `wsl.quiz` — у каждого читателя свой, никто не видит чужой.

## Сборка

Курс собирается из частей в `src/`, чтобы не редактировать 550 КБ одним файлом.

```bash
python3 build.py    # src/ → index.html
node qa.js          # 10 гейтов проверок
```

`qa.js` — самописный харнесс без зависимостей: компиляция скриптов, smoke-прогон лаб в DOM-стабе, 2250 вызовов обработчиков с выходом за границы диапазонов, баланс HTML-тегов, валидация квизов, a11y, сканы на посторонние алфавиты и приватные данные, проверка ссылок.

## Деплой

`index.html` самодостаточен — кладётся на любой статический хостинг как есть. Для Pages: **Settings → Pages → Deploy from a branch → `main` / `(root)`**.
